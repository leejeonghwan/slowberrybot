핵심 주장.
박균택은 조희대 대법원장이 한덕수 총리를 만난 적이 있느냐는 질문에 답변을 바꿨다며, 시기만 다를 뿐 만났다는 의미 아니냐고 추궁했다.
핵심 데이터.

"시기만 다를 뿐 한덕수 총리를 만났다는 의미 아닙니까?"
